## About

I use this GitHub as a workspace for learning, building, and refining small software projects. Most of what I make is practical: tools for studying, dashboards, automation, and desktop workflow experiments.

I am especially interested in:

- building useful web apps with React, TypeScript, Vite, and simple backend services
- working with Python for data-oriented projects and dashboards
- improving personal productivity through Windows automation and custom desktop tooling
- learning by shipping small, real projects instead of keeping everything theoretical
